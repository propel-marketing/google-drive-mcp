# Issue Prioritization

Priority rubric:
- CRITICAL: breaks core mission flow or causes data loss/state corruption
- MAJOR: blocks key workflows or produces repeated failures for real users
- MINOR: aesthetic or secondary quality issue without blocker impact
- ENHANCEMENT: behavior is fragile but not yet breaking

For each issue include:
- acceptance criteria with observable checks
- likely owner (route/service/job/frontend/backend/agent)
- test idea
